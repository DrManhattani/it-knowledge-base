# 🚦 git status

> [!ABSTRACT] Суть
> В системе Git отображает состояние рабочего каталога и индекса (staging area). Она показывает:
> - изменения, которые были добавлены в индекс и готовы для коммита;
> - изменения, которые ещё не были добавлены;
> - неотслеживаемые файлы, которые только попали в проект.

---

> [!INFO] 🔍 1. Базовая инспекция (Standard)
> | № | Команда | Описание |
> | :-- | :--- | :--- |
> | 1 | `git status` | Полный вывод: текущая ветка, staged, modified и untracked файлы. |
> | 2 | `git status -u` | Уточнение отображения **untracked** файлов (по умолчанию `all`). |

> [!EXAMPLE] ⚡ 2. Краткий формат (Short Mode)
> Идеально подходит для больших проектов, чтобы не прокручивать терминал.
> 
> | № | Команда | Описание |
> | :-- | :--- | :--- |
> | 1 | `git status -s` | **Short.** Выводит только статус-коды (напр. `M`, `A`, `??`) и пути к файлам. |
> | 2 | `git status -sb` | **Short + Branch.** То же самое, но сверху добавляет информацию о ветке. |

> [!SETTINGS] 🛠️ 3. Продвинутые параметры
> | № | Команда | Описание |
> | :-- | :--- | :--- |
> | 1 | `git status --ignored` | Показать файлы, которые обычно скрыты (из `.gitignore`). |
> | 2 | `git status --show-stash` | Показать количество записей в твоем "тайнике" (stash). |

---
### 💡 Как читать короткие коды (`-s`)?

Когда ты используешь краткий режим, Git выводит две колонки перед именем файла:
* **Левая колонка**: Статус в **Индексе** (Staged).
* **Правая колонка**: Статус в **Рабочей директории** (Modified/Untracked).
>[!TIP] Схема двух колонок `XY filename.txt`
>- **X** (лево) — что уже «заряжено» для коммита (**Index**).
>- **Y** (право) — что просто валяется измененным в папке (**Worktree**).
>- *Если видишь пробел слева — значит* `add` *еще не нажимали.*

| Код  | Значение                                                                                         |
| :--- | :----------------------------------------------------------------------------------------------- |
| `??` | **Untracked**. Новый файл, который Git еще не отслеживает.                                       |
| `A ` | **Added**. Файл добавлен в индекс (Staged). Этого пути (файла) раньше не существовало в истории. |
| ` M` | **Modified**. Файл изменен в папке, но изменения не добавлены в индекс.                          |
| `M ` | **Staged**. Файл уже был в прошлом коммите, но сейчас ты «зарядил» его новую версию.             |
| `UU` | **Unmerged**. Файл с конфликтом слияния (нужно твое вмешательство).                              |
