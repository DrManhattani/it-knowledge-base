# ⚙️ git config

> [!ABSTRACT] Суть
> Настраивает параметры конфигурации. Эти параметры контролируют различные аспекты работы Git, включая информацию о пользователе, предпочтения редактора, настройки для конкретного репозитория и другие.

---

> [!INFO] 🔍 1. Просмотр настроек (Reading)
> | № | Команда | Описание |
> | :-- | :--- | :--- |
> | 1 | `git config --list` | Показать **все** активные настройки. |
> | 2 | `git config --list --show-origin` | Просмотр с указанием **путей к файлам**-источникам. |
> | 3 | `git config --list --show-scope` | Показать **уровень** каждой настройки (local, global...). |
> | 4 | `git config --global --list` | Список только **глобальных** настроек пользователя. |
> | 5 | `git config <key>` | Узнать значение конкретного ключа (напр. `user.name`). |

> [!EXAMPLE] ✍️ 2. Задание параметров (Writing)
> | № | Команда | Описание |
> | :-- | :--- | :--- |
> | 1 | `git config --global user.name "Artem"` | Установка имени автора (глобально). |
> | 2 | `git config --global user.email "mail@ya.ru"` | Установка электронной почты. |
> | 3 | `git config --global core.editor "code --wait"` | Назначение редактора (напр. VS Code). |
> | 4 | `git config --global core.autocrlf true` | Настройка окончаний строк для Windows. |
> | 5 | `git config --global init.defaultBranch main` | Имя ветки по умолчанию для новых репозиториев. |

> [!DANGER] 🗑️ 3. Удаление и правка (Management)
> | № | Команда | Описание |
> | :-- | :--- | :--- |
> | 1 | `git config --global --unset <key>` | **Удалить** конкретную настройку. |
> | 2 | `git config --global --edit` | Открыть глобальный файл конфига в **редакторе**. |
> | 3 | `git config --local --unset-all <key>` | Удалить **все** вхождения ключа в локальном конфиге. |

---
### 💡 Важные нюансы

> [!TIP] Приоритетность уровней
> Если одна и та же настройка задана на разных уровнях, Git выберет ту, что «ближе к телу»:
> 1. **Local** — самый высокий приоритет.
> 2. **Global** — средний.
> 3. **System** — самый низкий.
